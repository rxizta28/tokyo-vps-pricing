## 影响东京 VPS 价格的三大核心因素

把价格拆开看，决定一台东京 VPS 卖多少钱的，主要是这三件事。

**第一，线路质量。** 这是最大的变量。同样是东京机房，线路可以分成好几层：

- **CN2 GIA**：电信的精品线路，回程走 GIA，晚高峰稳如老狗，价格最贵

- **AS9929（联通 A 网）**：联通的高端线路，质量接近 CN2 GIA

- **CMIN2**：移动的精品回程，移动用户福音

- **软银**：日本本土运营商直连，联通和移动用户友好

- **IIJ**：日本第二大 ISP，双程 IIJ 优质但晚高峰有概率拥堵

- **BGP 普通直连**：最便宜，晚高峰表现看天吃饭

一条"三网精品"线路（电信 CN2 + 联通 9929 + 移动 CMIN2 同时具备），价格往往比单线路贵 50% 以上。GoMami 走的就是这条路。

**第二，硬件配置。** CPU 代际直接决定单核性能。同样是 2 核，AMD EPYC 7763（3.5GHz）和 AMD Ryzen 9 9950X（5.7GHz）跑分能差出一大截；NVMe SSD 比 SATA SSD 快好几倍；DDR5 比 DDR4 内存带宽高。这些在跑 MySQL、跑容器、跑编译的时候，体感差距非常明显。

**第三，流量与带宽。** 东京 VPS 普遍是计量流量，500GB、1TB、2TB、5TB、10TB 这样往上加。带宽端口从 1Gbps 到 5Gbps 不等。流量用超了怎么办？有的商家停机，有的限速到 20KB/s，有的按 GB 计费——这点买之前一定要看清楚。

## 东京 VPS 选购避坑指南

东京 VPS 这摊水不算浅，几个坑提前告诉你：

**坑三：流量算不清楚。** 1TB 听起来不少，但如果你跑大文件下载、做镜像站、跑爬虫，可能一周就用完。用超了是停机还是限速，买之前看清楚条款。GoMami 是限速到 20KB/s 不停机，这点还算厚道。
